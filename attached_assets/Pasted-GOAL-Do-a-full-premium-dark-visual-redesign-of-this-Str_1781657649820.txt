GOAL

Do a full premium dark visual redesign of this Streamlit app so it looks like a high-end AI analytics product in the register of Linear, Vercel, and Palantir, while still feeling appropriate for an academic faculty tool. This is a visual presentation pass only.

Change the font, background, cards, layout polish, sidebar, tabs, buttons, inputs, tables, expanders, and native Streamlit widget styling where possible. Do not just restyle cards. The goal is to reduce the default Streamlit look across the whole app.

Keep it tasteful, high-contrast, and professional. Do not make it neon, cartoonish, crypto-looking, or overly futuristic.

HARD RULES

* Presentation only.
* Do not change the database.
* Do not change saved reflections or results.
* Do not change imported data.
* Do not rerun the model.
* Do not clear any tables.
* Do not change the model prompt.
* Do not change scoring logic.
* Do not change label rules.
* Do not change action logic.
* Do not change Evidence calculations.
* Do not change Robustness Check calculations.
* Do not change any formula.
* Do not hardcode any displayed number, count, gap, percentage, ranking, or action label. Read values from the existing computed results exactly as the app does now.
* Every number and label currently shown should remain the same after the redesign.
* Do not break the confidence slider, topic selectbox, textarea, form submission, dashboard tabs, Evidence tab, Robustness Check, import logic, or model-run button behavior. Style them only.
* If a visual change would require changing data logic, calculation logic, or model logic, skip that change.
* Render all custom HTML through `st.markdown(..., unsafe_allow_html=True)`.
* Never render HTML as a code block with `st.code`, `st.text`, or visible markdown.
* The calibration grid must render as a real styled 2x2 grid, not as visible code.
* Do not hide Streamlit errors with CSS.
* Do not add new Python package dependencies.
* Do not use matplotlib.

TECH SETUP

Create or update `.streamlit/config.toml` with a cohesive dark theme:

[theme]
base="dark"
backgroundColor="#0B0B12"
secondaryBackgroundColor="#14141C"
primaryColor="#A06BFF"
textColor="#ECECF2"
font="sans serif"

Use Inter as the preferred font if it loads successfully:

@import url('https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600;700;800&display=swap');

Apply this font stack across the app:

Inter, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif

Use `font-variant-numeric: tabular-nums` for large stat numbers.

If Google Fonts does not load, the app should still look good using the system font fallback.

DESIGN TOKENS

Use these values consistently:

* Base background: #0B0B12
* Background effect: subtle radial glow, for example radial-gradient(1200px 600px at 50% -10%, rgba(160,107,255,0.10), transparent 60%) layered over #0B0B12
* Panel/card background: #14141C
* Elevated panel: #1A1A24
* Hairline border: #262633
* Card shadow: inset 0 1px 0 rgba(255,255,255,0.03), 0 12px 30px rgba(0,0,0,0.45)
* Text primary: #ECECF2
* Text secondary: #9A9AAC
* Accent: #A06BFF
* Accent hover: #B98CFF
* Radius: 14px for cards
* Radius: 10px for buttons and inputs
* Radius: 999px for pills

Semantic colors for dark mode:

* understands green: #3DDC97
* confident_but_wrong red: #FF5C6C
* underconfident blue: #5AA9FF
* knows_confused amber: #F5B544
* partial lavender: #C4B5FD

Use semantic colors as thin accents, badges, labels, stripes, and heatmap colors. Do not use full bright color fills everywhere.

GLOBAL CSS

Create a shared global CSS layer that reduces the default Streamlit look.

Apply:

* Dark page background with subtle radial glow.
* Optional very faint grid texture at low opacity, only if subtle.
* Center main content in a max-width container around 1180px to 1240px.
* No horizontal scrolling at 100% browser zoom.
* Inter/system font across headings, body, tables, widgets, and form controls.
* Headings with tight spacing, weight 700 to 800, letter-spacing around -0.02em.
* Secondary text in #9A9AAC with enough contrast to read comfortably.
* Cards with #14141C background, #262633 border, subtle shadow, 14px radius.
* Consistent spacing between sections.

Restyle native Streamlit chrome where possible:

* Sidebar: dark panel, hairline right border, active nav item with violet left bar and brighter text.
* Tabs: clean underline or segmented style. Active tab uses violet accent and bright text. Inactive tabs use muted text.
* Buttons: primary solid violet #A06BFF, dark or white readable text, soft glow 0 6px 20px rgba(160,107,255,0.28), hover lift translateY(-1px), hover color #B98CFF.
* Inputs, selectbox, slider, textarea: dark field #14141C, hairline border #262633, violet focus ring. Slider filled track uses violet accent.
* Expanders: dark panels with clean header row, hairline border, rounded corners.
* Dataframes and tables: dark rows, hairline separators, hover row #1A1A24, muted uppercase headers, readable numbers.
* Action pills: dark pill background with semantic text/border color.

Avoid brittle CSS that breaks Streamlit widgets. If a widget cannot be safely restyled, leave it functional and style its surrounding panel instead.
